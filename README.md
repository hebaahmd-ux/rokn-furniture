# ROKN — Furniture & Décor

نسخة Front-end من مشروع رُكن باستخدام HTML وTailwind CSS وCSS variables وJavaScript، مبنية على تصميمات الديسكتوب والتابلت والموبايل المرسلة.

## التشغيل

1. فكّي ضغط الملف.
2. افتحي فولدر `Rokn` في VS Code.
3. شغّلي `index.html` باستخدام إضافة Live Server، أو افتحي Terminal داخل الفولدر واكتبي:

```bash
python -m http.server 8000
```

ثم افتحي `http://localhost:8000`. لا تحتاجي npm أو تثبيت dependencies. الخطوط والأيقونات وTailwind والصور موجودة محليًا. الأفضل تشغيله باستخدام Live Server بدل فتح الملفات مباشرة حتى تكون البيانات مشتركة بين الصفحات بشكل ثابت.

## تجربة الموقع

- زر القمر/الشمس يبدّل بين اللايت الكريمي والدارك البراون، ويحتفظ بالاختيار.
- أول تشغيل يحتوي على 3 منتجات في السلة لتمثيل التصميم المرسل. يمكن إزالتها وتجربة الإضافة من أي منتج.
- الكوبون التجريبي: `ROKN10`، خصم 10%.
- الأسعار موحّدة بالجنيه المصري بدل المزج بين الدولار والجنيه في التصميم.
- الشحن العادي 250 جنيه، ومجاني للطلبات من 2000 جنيه. الشحن السريع 550 جنيه.
- إتمام الـCheckout يحفظ طلبًا تجريبيًا ويقلّل المخزون، وتظهر بيانات الطلب داخل الداشبورد.
- يمكن تعديل حالة الطلب. إلغاؤه يعيد المخزون، وإعادة فتحه تتحقق من المخزون وتخصمه.
- التسجيل واستعادة كلمة المرور واجهات تجريبية. رمز التحقق: `123456`. لا تُرسل رسائل إيميل ولا تُحفظ كلمات المرور. تسجيل الدخول يقبل بيانات تجريبية ويُنشئ جلسة محلية فقط، وليس تحققًا حقيقيًا.
- الداشبورد تحتوي على المنتجات والمخزون والطلبات والعملاء والتقارير والإعدادات وتصدير CSV. إضافة وتعديل وحذف المنتجات ينعكس على المتجر في نفس المتصفح.
- تقارير الداشبورد تبدأ بدون مبيعات، ثم تتحدّث عند إنشاء طلبات؛ لا توجد أرقام مبيعات مختلقة.
- الإيصال: Print / Save PDF Receipt يفتح نافذة الطباعة؛ اختاري Save as PDF.
- روابط السوشيال عامة، واستبدليها بروابط البراند الحقيقية قبل النشر.

## تنظيم الكود

- `assets/styles.css`: التصميم المشترك، ألوان اللايت والدارك، وتجاوب الشاشات.
- `assets/catalog.js`: بيانات المنتجات الافتراضية.
- `assets/app.js`: المتجر والسلة والطلبات والمفضلة والحساب التجريبي.
- `assets/dashboard.js`: إدارة المنتجات والطلبات والتقارير والتصدير.
- `assets/theme.js`: تطبيق الثيم المحفوظ قبل ظهور الصفحة.
- `assets/fonts.css` و`assets/fonts/`: الخطوط المحلية.
- `assets/tailwind-browser.js`: نسخة Tailwind Browser 4.3.3 المحلية المستخدمة في صفحات HTML.
- `img/`: الصور واللوجو من ملفات المشروع الأصلية.

## حدود النسخة

هذه نسخة Front-end مناسبة للعرض وتجربة الواجهات، وليست متجرًا جاهزًا لاستقبال عملاء أو دفعات حقيقية. البيانات محفوظة في browser storage على نفس الجهاز. صفحات الإدارة ليست محمية بتسجيل دخول حقيقي. تحويل المشروع لمتجر فعلي يحتاج API وقاعدة بيانات وتوثيق وصلاحيات آمنة وإرسال إيميل وتكامل بوابة دفع وتحقق من المخزون والأسعار على السيرفر.

صور تفاصيل المنتج الثلاث تستخدم نفس الصورة بمواقع قص مختلفة، لأن الصور الأصلية لا تتضمن زوايا أخرى لهذا المنتج. الأيقونات تستخدم Font Awesome Free الموجود في المشروع بدل بعض أيقونات Pro أو SVG التي لم يتاح تصديرها من Figma.

باقي صفحات التسجيل تم استكمالها بنفس نظام تصميم الـLogin والـSign up كما طلبتِ. الداشبورد تصميم مخصص لهوية رُكن وليست شاشة موجودة في Figma.

يمكن استعادة البيانات الافتراضية من Dashboard → Settings → Reset this device’s demo. هذه العملية تمسح الطلبات والبيانات التجريبية وتعديلات المنتجات على هذا الجهاز.

## المراجعة

تم اختبار تفاعلات السلة والمفضلة والفلاتر والكوبون والشراء وتحديث المخزون وحالات الطلب وإضافة المنتجات والتسجيل والتحقق واستعادة كلمة المرور. وتم فحص الصفحات الأساسية بعروض 375 و900 و1440 بكسل في الوضعين اللايت والدارك مع حظر أي طلبات إنترنت خارجية للتأكد أن الملفات المحلية كافية للتشغيل.

## النشر لاحقًا

يمكن رفع محتويات فولدر `Rokn` على GitHub Pages أو استضافة ملفات Static. كل الروابط والمسارات نسبية لتعمل داخل فولدر أو repository. لا تحتاجي رفع أي بيانات تجربة من المتصفح؛ هذه البيانات لا تدخل في ملفات المشروع.

قبل نشر متجر إنتاجي: استبدلي نسخة Tailwind Browser ببناء CSS للإنتاج، وأكملي خدمات الباك إند المذكورة أعلاه.
